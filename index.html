PVL Wuji rclone

A personal backup utility operated by Zichen Wang using rclone. Google OAuth allows the operator to transfer and manage their files in Google Drive.

This application is intended for the operator's personal use. This informational website does not provide a login, receive Google credentials, or host backup data.

Drive access is used to list existing folders and files and to upload, download, or manage files as explicitly requested by the operator. No research files or configuration secrets are published on this website.
