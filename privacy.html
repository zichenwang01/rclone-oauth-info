Privacy policy

PVL Wuji rclone · Effective October 1, 2026

Purpose and data access

This is a personal backup utility operated by Zichen Wang. With the account holder's consent, rclone accesses Google Drive file contents and metadata to list, upload, download, verify, and manage files as requested. The full Drive scope is used to work with existing files and folders, including those not created by this application.

Storage and use

File transfers take place between the operator's configured computers and Google Drive. OAuth credentials are stored in access-restricted rclone configuration on those computers. Backup contents remain in the locations selected by the operator; this website does not receive or store those contents or credentials.

Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models. Access is used only to perform the requested file-management operations. This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and control

Files remain until the operator removes them, subject to the storage provider's retention policies. The account holder can revoke authorization in Google Account connections and remove local rclone credentials. Revoking access does not delete files already stored in Google Drive or on the operator's computers.

This website

This static informational site uses no application analytics, advertising, or login forms. GitHub Pages hosts the site and may process ordinary access logs under GitHub's privacy statement.

Contact

Contact Zichen Wang on GitHub with privacy questions. Do not post credentials or private files in public issues.
